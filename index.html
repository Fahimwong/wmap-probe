T6 · signing bisection (FREE — signs only, sends NO transaction)

Walks from the simplest possible signature up to our full permit and stops at the first failure, so we learn exactly which field World App rejects. No gas. No WLD. Nothing broadcast.

You may see up to 6 signing prompts. Approve each one. If a prompt fails, the run stops there and reports the culprit. If you deliberately cancel one, it will show user_rejected and stop.
